> 이 파일은 `_drafts` 폴더에 있어서 사이트에 게시되지 않아요.
> 복사해서 `_posts/YYYY-MM-DD-영문-주소.md` 로 저장하면 글이 올라갑니다.

본문 첫 문단입니다. **굵게 쓴 부분**은 포트폴리오처럼 형광펜 효과가 들어가요.

## 소제목 (h2)

문단 안에 `인라인 코드`나 [링크](https://github.com/jangsh7)를 넣을 수 있어요.

### 작은 소제목 (h3)

1. 순서 있는 목록
2. 두 번째 항목

- 순서 없는 목록
- 두 번째 항목

```python
def hello(name: str) -> str:
    # 코드 블록은 언어 이름을 적으면 색이 입혀져요
    return f"안녕하세요, {name}!"
```
