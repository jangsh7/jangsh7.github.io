글 쓰기

게시하면 GitHub 저장소 _posts 폴더에 마크다운 파일로 저장되고, 1~2분 뒤 블로그에 올라가요.

이 브라우저에서 처음 쓰시나요?

  1. GitHub → Fine-grained token 만들기 ↗
  2. Repository access: Only select repositories → {{ site.writer.repo }}
  3. Permissions → Repository → Contents: Read and write
  4. 만든 토큰(github_pat_…)을 아래에 붙여넣기
